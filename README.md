# DeepSea_ReleaseSystem
Code and model files for release system for URIL.
FDM (step) files:
Internal housing holds Arduino BLE 33, step down converter, clock, 9-v battery and Blue Robotics ESC.
Motor holder attaches to back of Blue Robotics motor and can be attaches to overall release system.  
Motor top attaches on top of Blue Robotics motor and semi-rigid cable can be attached. 
Pressure house mount holds pressure housing. Mount can be attached to release system base by screws and/or zipties.

Formlab files:
Body release pressure housing body (add dimensions)
Endcap release pressure housing endcap (uses _ screws and nuts)
